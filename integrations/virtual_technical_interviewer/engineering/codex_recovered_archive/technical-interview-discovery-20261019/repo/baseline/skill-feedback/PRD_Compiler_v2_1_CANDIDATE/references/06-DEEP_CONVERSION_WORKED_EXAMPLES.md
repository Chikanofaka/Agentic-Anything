# Deep Conversion Demonstrations — How a specific source becomes a universal rule

> These are NOT generic renamings. Each item reconstructs the original decision purpose, the persistent principle, a rule for an unknown future Need, the target artifact and an out-of-domain falsification example. Summaries do not reproduce sensitive source paragraphs verbatim.

## Example 01 · S01, PDF p2–3
**Observed structure (paraphrased):** PRD begins with why / what / how / value / acceptance.
**Underlying reason (why that passage needed to exist):** A document must let distinct stakeholders make a named decision.
**Universal generation rule:** Given a new Need, map stakeholders and their decision questions, write exactly five contract clauses and attach evidence/unknown markers.
**Meta paragraph / target artifact:** Produce Executive Summary + document purpose + decision memo based on {new user / scenario}, {trigger}, {constraints}, {evidence}, {required decision}, {success criterion}. Never reuse the old scenario’s named entities or quantitative values.
**Reverse-domain proof:** A new local tutoring app asks for why, use case, time/cost, data safety and success before model selection.
**Audit query:** Could a builder follow this new instruction without consulting or knowing the original case? Can the user challenge it with a counterexample?
