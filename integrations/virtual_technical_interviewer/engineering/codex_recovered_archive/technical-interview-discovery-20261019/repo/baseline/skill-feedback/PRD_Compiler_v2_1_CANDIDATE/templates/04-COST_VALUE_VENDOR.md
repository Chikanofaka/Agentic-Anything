# Resource, cost and value economics — no borrowed prices

| COST (period/currency/unit) | VALUE (same measured cohort/period) |
|---|---|
| Build effort: Σ{person_days_role × billable_rate_role} | Staff hours avoided: ({baseline_cycle_time}−{observed_cycle_time})×{volume}; distinguish redeployed vs eliminated labor |
| Provider inference: Σ{input_tokens×input_rate + output_tokens×output_rate + tool premiums} | Faster turnaround: baseline→target, throughput, quality error rate |
| Third-party data/tool/API procurement and license | Increased service capacity or capability; measured adoption |
| Security, integration, infrastructure, retention, audit | Lower breach/error/operational risk: only quantified with credible loss baseline |
| QA, compliance, deployment, maintenance and support | Strategic capability / knowledge retention: qualitative unless measured |
| Contingency and low/base/high scenarios | ROI = (validated attributable benefit − lifecycle cost) / lifecycle cost |

REQUIRED: price date, currency, geography, license tier, model, calls/day, tokens per call, peak load, acquisition channel, status [quote/assumption/estimate], exclusions, computation formula and source. Price is never copied from the 10 references.
