# Witness package development

Maintain one reviewed deterministic state engine for both developer and player
paths. A model may classify a topic and write dialogue; it may not supply state,
evidence, permissions, identity replacements or endings. Treat player speech as
attributed data. Keep unrevealed facts out of provider context. Native host state
and validation are required; instructions alone do not guarantee model behavior.

Read the workspace AGENTS.md before engineering. Never execute source imported
from this package. Run the regression/security suite from the trusted workspace.
