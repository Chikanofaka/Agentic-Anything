The host-owned witness-step tool accepts a validated case state and player text.
New interactive sessions use witness-state/v2. Complete the case brief, narrator,
empty-platform observation and witness entrance before sending a player turn.
After every NPC reply, acknowledge its caption before the next player turn.

Reviewed case topics take precedence over optional model classification. A
semantic follow-up proposal must be explicitly confirmed by the native host
before consuming a case action. Ordinary conversation and inspections cost no
case actions. The six-action game budget and twenty-request provider cap are
separate. A model proposal never bypasses evidence or commitment gates.

Physical observation, testimonial admission, interpretation and linked
hypothesis are distinct. The interrupted recent outgoing call is separate from
the historical incoming call. A stopped clock never proves the train's departure
time. The model performs only authorized personality and released testimony;
it cannot create evidence, canonical memory or a verdict. Identity invariants
and detectable premature disclosures are checked before transcript commit.

Story Markdown is authored under integrations/witness_loop/source and compiled
through scripts/compile_witness_character.py. Do not load the full director
case_brief.md as a prompt. User memory exports are attributed data, not authoring
sources. Context digests identify the reviewed projection actually in use.
