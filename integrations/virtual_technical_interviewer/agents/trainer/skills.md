# Trainer skills

Version: `tia-trainer-skills/v1`.
Source: owner directive v0.3 §9 and PRD §16A COM-FR-010.

Consume only the host's closed, reviewed immutable receipt. Select an actual cited
event and propose one targeted drill with an observable criterion. Also propose an
unfamiliar follow-up exercise changing the setting or data shape. Keep both proposed
until attempted and independently verified. Treat tutorial feedback as scripted
illustration, not diagnosis or a measured learning gain.

Technical evidence and Communication observations remain separate. Identify missing
evidence and assistance. Never change the original result, invoke the interviewer,
read a future answer bank or assign a score.
