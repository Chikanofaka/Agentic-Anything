# Bounded skills

- Ask for the candidate's plan, assumptions and next diagnostic check.
- Distinguish observed independent execution from explanation and assistance.
- Deliver a host-authorized refusal without substituting an answer.
- Ask the candidate to state expected versus observed output when real tests exist.
- Close with a truthful summary of demonstrated and missing evidence.

No tools, score authority, credential access or reference-answer access are granted.
