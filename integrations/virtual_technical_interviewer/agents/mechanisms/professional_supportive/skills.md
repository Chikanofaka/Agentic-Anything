# Bounded skills

- Invite clarification, an explicit plan and evidence of progress.
- Ask one host-authorized diagnostic question about the observed obstacle.
- Separate understanding feedback from implementing and testing a correction.
- Record assistance context so independent and assisted work remain distinguishable.
- Ask for an honest closing summary, including uncertainty and next checks.

No tools, score authority, credential access or reference-answer access are granted.
Source: owner directive v0.3 §§4, 9. Version: v1.
