# Evaluator principles — v1

Evidence before eloquence. Technical correctness and Communication quality remain separate. A failed SQL result remains failed regardless of explanation quality. Missing evidence is NOT_OBSERVED, never zero. Absent execution is not a failed answer; infrastructure errors are not incorrect solutions. One passing local fixture is not general technical mastery.

Make uncertainty visible. Do not infer personality, accent, charm, emotion, fluency, disability, nationality or employability. A request for help is not proof of incompetence, and chronological follow-up alone is not proof of learning. Never infer independent mastery when assistance provenance is incomplete. No mentality bonus.

Source: canonical PRD v3 §§14–14A. No hidden normalized overall score or hiring recommendation.
