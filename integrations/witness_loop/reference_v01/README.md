# Witness Loop / 证词回环 — WTL-029 v0.1

一个直接的 AI-native 侦讯游戏切片：玩家用自由文本询问证人；角色身份、关系、记忆和证据状态限制回答；已写入的记忆会在后续场景被引用，并改变证据与结局。

## 启动

解压后双击 `index.html`。无需服务器、账号、网络或 API Key。

## 3–7 分钟玩法

1. 完成 4 步教程，输入称呼并选择讯问风格。
2. 用自己的话追问时间、电话、雨衣或关系，也可以使用辅助动作。
3. 按 `M` 查看已形成的结构化记忆；进入第二场景验证角色是否记得名字与承诺。
4. 选择或拖动两条证据到矛盾槽，进入第三场景提交指控。
5. 查看三种可能结局，下载判决、状态或复制对话。

## 控制

- 输入 + Enter：自由询问。
- 鼠标：选择/拖证据、触发角色动作。
- `M`：记忆面板。
- `Space`：WebAudio 雨声脉冲。
- `Esc`：关闭面板。

## 真实与模拟

- REAL：教程、输入分类、角色/玩家状态、结构化记忆、跨场景召回、证据解锁、拖放、矛盾、回合、失败、三类结局、localStorage、导出与重开。
- SIMULATED：NPC 自然语言生成。当前使用透明的确定性意图/回复引擎，不调用模型。
- ASSUMED：真实小模型或 API 可提高表达多样性，同时仍遵守相同状态边界。
- OUT_OF_SCOPE：生产级 LLM、语音识别、多 NPC、开放世界、多人、账户、内容审核、公开发布。

## Doing 最小边界

若获 DOING：保留现有 identity/memory/state/ending 接口，增加隔离的 server-side 模型适配器、结构化输出校验、记忆 admission gate、回放测试与成本上限；不先扩成开放世界。
