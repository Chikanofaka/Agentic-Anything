# HAL-P2D-001 · Need→PRD Compiler Pilot · v2.0

## What changed
HAL v1 showed two onboarding paths with a single research calculator. HAL v2 runs the latest reference-abstraction compiler's 32-section PRD process, adds traceability, candidate ideation, typed capability constraints, second distinct domain fixture, direct product MVM and proposed recursive Skill improvements. This is a human-verifiable Ready MVM, **not** a production LLM agent runtime.

## Open in under a minute
1. Extract this ZIP.
2. Double-click `ready-mvm/index.html` in your browser (works without network for bundled actions; browser security policies may vary by OS).
3. Try Path A, Key Academy, AI simulation, Research calculation, swap to Returns, UAT.
4. Read `HUMAN_UAT.md` and export feedback JSON. Do not paste real keys anywhere in this demo.

## Which file to use for what
- `prd/HAL_PRD_v2_0.md`: complete 32-section product requirements document.
- `prd/HAL_PRD_v2_0.docx`: Word layout for product/engineering review.
- `prd/NEED_NORMALIZED.md`: normalized user Need; distinguishes source truth from proposed means.
- `prd/IDEATION_DECISION.md`: alternatives and provisional idea winner.
- `prd/TRACEABILITY.csv`: N→F→T mapping.
- `prd/UAT_MATRIX.md`: functional and negative contract.
- `prd/ARCHITECTURE_OPTIONS.md`, `prd/ASSUMPTIONS_AND_OPEN_QUESTIONS.md`, `prd/SOURCE_AND_DECISION_LEDGER.md`: architecture, unknowns, source truth.
- `prd/PRD_QUALITY_RECEIPT.md`: author-quality self-score and limits.
- `ready-mvm/index.html`: interactive high-fidelity shell, no key.
- `ready-mvm/research-harness.zip`, `ready-mvm/returns-harness.zip`: two real developer source examples.
- `examples/`: extracted corresponding deterministic Python packages.
- `HUMAN_UAT.md`: 5–7 minute walkthrough and human scorecard.
- `CODEX_HANDOFF.md`: conditional approved future sprint brief.
- `receipts/TEST_RESULTS.md`, `quality/browser_checks.json`: actual test evidence and debt.
- `skill-feedback/PILOT_RECURSION.md`, `skill-feedback/PRD_Compiler_v2_1_CANDIDATE/`: proposed Skill self-refinement, **not installed**.

## Boundaries
REAL: offline UX, source pack, deterministic tools, downloads. SIMULATED: all AI/provider results. OPEN: first actual operating system target, legal real repos, model choice, budget. Human Gate=PENDING. No automatic Trello state change or GitHub publication occurs from the webpage.
