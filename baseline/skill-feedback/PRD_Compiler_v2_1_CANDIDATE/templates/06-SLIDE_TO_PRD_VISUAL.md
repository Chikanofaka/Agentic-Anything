# Slide/diagram → PRD visual semantics (not theme copying)

| Original graphic type | Generative purpose | New-Need input | Standardized output | Proof check |
|---|---|---|---|---|
| Cover/title | Declare scope and audience | Product name, decision, version, owner | Identity card | No unsupported strategic promise |
| Agenda/divider | Explain reading order and decision progression | Need->solution->risk->cost->decision | Section navigation | Slides trace back to PRD chapters |
| Problem / path / action grid | Transform stakeholders' vague pain into operational response | Facts, process bottlenecks, alternatives | Need/problem/option table | Each row has measured outcome |
| Gantt/timeline | Show sequential and concurrent work | Resources, dependencies, exit checks | Workstream swimlane | Critical path and owners visible |
| Product capability mind map | Decompose system into modules and jobs | Persona, task families, prerequisites | Capability tree | Features have jobs/outputs |
| Three-layer system diagram | Explain data trust, computation, UI | Inputs, computation, boundaries, presentations | Directed and labeled architecture | Arrows have input/output contracts |
| Security / account graphic | Show principals, assets, rules | Roles, data classes, actions | Permission lattice/matrix | Forbidden access visibly denied |
| Feature detail table | Make scope measurable | Feature trigger/input/behavior/output | FR specification grid | Negative path included |
| Interaction / UI screenshot | Validate human comprehension and flow | Journey, controls, states | Screen specification + annotated frame | Interaction supports real target task |
| Cost/value two-column view | Compare full cost burden with credible benefit | Price/effort drivers and adoption baseline | Side-by-side cost-value | Units and assumptions visible |
| Stage deliverable / value accounting | Enable resourcing and governance | WBS, owners, milestones, evidence | Stage acceptance scorecard | Every milestone has proof |
| Vendor/contract table | Make procurement answerable | Scope, SLA, licence and exclusions | RFP response form | All vendors answer same questions |

Render diagrams only when they advance a decision. Treat unreadable infographic labels as visual-review debt; do not invent missing words.
