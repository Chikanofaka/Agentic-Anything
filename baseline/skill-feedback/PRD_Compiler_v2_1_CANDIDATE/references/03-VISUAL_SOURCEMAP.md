## Visual transcription gate
Every unreadable label becomes `VISUAL_TEXT_PENDING_REVIEW`, not invented words. Design output should explain whether the slide encodes hierarchy, process, comparison, time, access or evidence. If actual copy is decision-critical, request human visual verification from the original.
