The host-owned witness-step tool accepts a validated case state and player text.
Hard case topics take precedence over optional model classification. Plot turns
consume the six-turn case allowance; ordinary conversation does not. Evidence,
admission memory, contradiction links and endings are computed by the reviewed
adapter. The model only narrates facts released for the current case state.

network permission or access to credentials is conferred by reading it.
